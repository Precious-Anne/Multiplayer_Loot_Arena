# Multiplayer_Loot_Arena
A basic multiplayer game where players get spawned in different spawn locations and collect as much loot as they can.

## Overall Approach

The game was developed using Roblox Studio, Luau and VS Code with the Rojo plugin. The game contains two of the main systems required with two left unfinished. I approached this game by breaking down the requirements in small easier to manage steps as it helps to think about how the logic of code should go. I started first with the basic layout of the map with no scripts. Similar to sketching in art, setting up the map first is like a foundation and makes it easier to build the game from there and add features since majority of the pieces are already there. After that, I listed down the main features I wanted to work on. I decided on what to do first by figuring which features are a higher priority and what the player will encounter first. With that, I made the random spawn point, loot system, and server counter my priority. I broke down these features one step at a time so that I can understand and design the logic of the code as I went along.

As I worked on this game, I used AI tools such as Gemini and ChatGPT as well as other scripting tutorials. Due to my limited experience with this, I wanted to make sure I understood what I was doing rather than just copying. I used these tools to practice what I knew from my own coursework and to further understand and develop what I know about Luau and Roblox scripting. However, these studies as well as my schedule through the weekend did lead me to be a bit slower than I wanted to be. This lead me to not being able to implement everything in the assignment.

## Completed

- Random Multiplayer Spawn
- Loot System & Server Leaderboard/Counter

The players upon entering the game are teleported randomly in either 4 different spawn points which encircle the map. They also spawn randomly in these areas when they respawn. 

The loot themselves are also spawned randomly in the map and respawn randomly after collection. This makes it so that the loot placements will not be predictable and make it more exciting for players to catch as many as they can.
